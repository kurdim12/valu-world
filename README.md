# The Value Behind Valu — touch table

Interactive touch-table story for the Valu Jordan launch (Kan Zaman, Amman, 12 Oct 2026).

**Live:** https://kurdim12.github.io/valu-world/

- Touch the orange points to open each chapter; EN | ع (top) switches English / Arabic.
- Pinch to zoom, drag to move, double-tap to zoom in/out.
- Works offline after the first visit (service worker): open the link once with internet, then it runs with none.
- Static site, no build step: `index.html` + `js/` + `css/` + `config/` + `assets/`.

The public build uses a fallback web font; the brand font is only in the offline board copy.
